# Time Series Analysis and Forecasting with R

## Project Overview

This repository contains an **individual coursework project** on time-series analysis and forecasting using **R**. The project applies time-series decomposition and ARIMA modelling to analyse patterns, assess model performance, and generate forecasts.

## Analysis Covered

### Part 1 – Time Series Decomposition

* Exploratory analysis of the time series
* Identification of trend and seasonal patterns
* Selection of an appropriate decomposition approach
* Moving average and centred moving average calculations
* Calculation of seasonal indices
* Deseasonalisation of the series
* Estimation of the underlying trend
* Forecasting future observations
* Interpretation of the results

### Part 2 – ARMA/ARIMA Modelling

* Exploration of the time series
* Assessment of stationarity using the Augmented Dickey-Fuller (ADF) test
* Examination of ACF and PACF plots
* Identification and comparison of candidate ARIMA models
* Model selection using information criteria
* Residual diagnostics
* Assessment of model adequacy
* Forecasting future observations
* Interpretation of forecast results

## Methodology

The analysis follows a structured time-series modelling process:

1. Explore the data and identify important patterns.
2. Examine trend and seasonality through decomposition.
3. Assess stationarity before ARIMA modelling.
4. Identify suitable ARIMA models using ACF and PACF behaviour.
5. Compare candidate models using model selection criteria.
6. Evaluate residuals using diagnostic tests.
7. Generate forecasts from the selected models.
8. Interpret the results and assess model adequacy.

## R Code

The R code used for the analysis is included separately in the repository as:

`ARIMA Time Series Forecasting.R`

The script contains the R code used for the time-series analysis, ARIMA modelling, diagnostic tests, and forecasting.
